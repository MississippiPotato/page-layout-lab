# 页面布局实战课 · Page Layout Studio

一个以真实案例为主线的中英双语教学网站。课程使用同一个 **Campus Pulse 数据看板**，从混乱初稿开始，依次完成问题诊断、视觉层级、网格与对齐、空间分组、响应式重排和最终布局审计。

这不是 Flex、Grid 或媒体查询的语法手册。课程重点是解释：**为什么这样布局、依据是什么、改变后解决了什么问题**。

## 课程结构

网站采用与参考课程相同的两层信息架构：

1. 课程门户展示全部章节、学习路线和理论来源。
2. 每个章节都有顶部跨章导航、左侧小节目录和前后章翻页。
3. 每个小节固定包含三个部分：
   - **📖 讲解**：案例问题、理论依据、判断规则、关键点与常见误区。
   - **⌨️ 关键代码**：与演示实际逻辑对应的 D3.js 代码及设计原因。
   - **▶️ 演示**：可调参数、动态过渡和即时反馈。

五个章节共包含 20 个教学小节和 20 个 D3.js 互动实验：

| 章节 | 主题 | 主要内容 |
| --- | --- | --- |
| 01 | 先诊断，再布局 | 布局审计、内容盘点、任务优先级、视觉层级、阅读顺序 |
| 02 | 网格、对齐与比例 | Container、Column、Gutter、共享边缘、栏宽比例、垂直节奏 |
| 03 | 空间分组与页面组成 | Gestalt 接近原则、共同区域、留白、信息密度、页面模式 |
| 04 | 响应式与可访问布局 | Reflow、内容优先级、文字缩放、触控空间、内容驱动断点 |
| 05 | Campus Pulse 综合重构 | 重构回放、拖拽布局、网格吸附、Layout X-Ray、多屏验证 |

## 主要亮点

- **案例连续**：同一组模块贯穿五章，形成“混乱初稿 → 逐步修复 → 最终方案”的完整故事。
- **中英一致**：中文和英文来自同一份课程数据，语言选择会写入 URL 和本地偏好，并在页面间保持。
- **D3.js 不是装饰**：D3 负责数据映射、对象更新、过渡、拖拽、网格吸附、阅读路径和诊断反馈。
- **Layout X-Ray**：把列、基线、尺寸、对齐误差和溢出问题显式标注出来。
- **教学反馈可解释**：布局评分拆分为层级、对齐、节奏和边界指标，并明确说明它只是教学启发式，不是客观审美标准。
- **响应式设计**：桌面端使用章节侧栏，移动端切换为小节选择器；互动图适配窄屏且不产生页面横向滚动。

## 本地运行

项目是纯静态网站，不需要安装 npm 依赖。进入项目目录后启动任意静态文件服务器即可：

```powershell
cd G:\可视化导论\1
python -m http.server 4173 --directory dist
```

然后访问：

```text
http://127.0.0.1:4173/
```

直接双击 `dist/index.html` 可能会受到浏览器本地文件策略限制，因此推荐使用上面的本地服务器方式。

## 项目目录

```text
.
├─ dist/
│  ├─ index.html         # 课程门户
│  ├─ course-data.js     # 中英双语课程内容与章节数据
│  ├─ portal.js          # 门户渲染和首页 D3 动画
│  ├─ lesson.js          # 章节渲染、语言切换和 20 个互动实验
│  ├─ styles.css         # 门户、章节、演示和响应式样式
│  └─ lesson-01/ ... lesson-05/
│     └─ index.html      # 五个独立章节入口
└─ readme.md
```

## 技术实现

- HTML5 + CSS3 + 原生 JavaScript
- D3.js v7（CDN）
- SVG 数据可视化
- `localStorage` + URL 参数保存语言状态
- GitHub Pages 静态部署

课程内容集中保存在 `dist/course-data.js`。需要修改标题、理论说明或翻译时，应优先修改这份数据；页面结构和交互逻辑分别位于 `portal.js` 与 `lesson.js`。

## 理论线索

课程内容主要围绕以下知识体系展开：

- Gestalt：接近、相似、共同区域等分组原则
- Edward Tufte：视觉层级与信息密度
- Stephen Few：看板信息设计
- W3C WCAG：重排、文字缩放与触控目标
- D3.js：Scale、Data Join、Transition 与 Drag
